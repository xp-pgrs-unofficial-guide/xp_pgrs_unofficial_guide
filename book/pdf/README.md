# PDF 排版

这里维护当前 Quarto PDF 的封面图片、LaTeX 样式与标题页片段。样式参考历史 ElegantBook 版的全幅校园封面、深蓝色封面横带、蓝色章节标题与页眉页脚；正文继续由当前 `.qmd` 生成。

网页采用“一级主题 → 二级专题 → 具体文章”三级目录。完整构建从共享目录树生成 PDF 专用章节配置，按网页顺序展开文章，仅保留一级主题及辅助分组，避免把二级专题生成为额外分卷。该配置按语言临时生成，完成渲染后删除，不手工维护或提交；正文仍只维护一份 `.qmd`。需要 PDF 时运行 `python3 scripts/build.py`，使该配置生效，网页预览继续使用 `quarto preview book` 或 `quarto preview book/en`。

拆分文章时，旧页保留旧小节锚点作为入口，迁出的标题使用新的主题前缀锚点；实际段落和署名块随正文移动，避免整本 PDF 出现重复定位标识。检查时同时核对目录顺序、分组、章节间跳转和资料日期。

`cover.jpg` 是历史版 `cover3.jpg` 的发布副本。构建不读取 `archive/`，使用 XeLaTeX、`ctexbook` 和发行版自带的 Fandol 中文字体。修改后应完整构建，并查看封面、目录、正文、表格和插图页。
